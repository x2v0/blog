# Веб-версия Android-приложения: от PR до бесплатного автотестирования

## Введение

У нашего Android-приложения есть веб-версия, которая функционально идентична нативному приложению на 100%. Изначально мы создали её как PR-инструмент: любой может попробовать программу в браузере, без установки на смартфон. Но в процессе мы обнаружили колоссальный профит.

## Основные тезисы

### 1. PR-инструмент

Веб-версия позволяет пользователю увидеть, как работает программа, ещё до скачивания APK. Это мощный маркетинговый ход и демонстрация возможностей.

### 2. Бесплатный инструмент для автотестирования

Поскольку веб-версия работает 1:1 с нативным приложением, мы получили бесплатный инструмент для автоматического тестирования GUI. Теперь мы используем Microsoft Playwright для запуска тестов на веб-версии через GitHub Actions при каждом пуше.

Это даёт:
* **Скорость:** тесты в браузере, а не в эмуляторе.
* **Простоту:** не нужен Android SDK.
* **Надёжность:** робот не устаёт и не пропускает шаги.
* **Экономию:** не нужен эмулятор или физическое устройство.

### 3. Замена ручной работы

Раньше тестирование GUI Android-приложения требовало ручной проверки на смартфоне. Теперь Playwright делает это автоматически. Человеческий фактор снижен к минимуму.

## Вывод

Веб-версия Android-приложения — это двойное преимущество. Во-первых, мощный PR-инструмент. Во-вторых, бесплатный инструмент для автоматического тестирования GUI, который заменяет ручную работу и снижает человеческий фактор.
