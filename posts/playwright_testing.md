# Веб-версия Android-приложения: от PR до бесплатного автотестирования

## Введение

У нашего Android-приложения есть веб-версия, которая функционально идентична нативному приложению на 100%. Изначально мы создали её как PR-инструмент: любой может попробовать программу в браузере. Но в процессе мы обнаружили колоссальный профит.

## Основные тезисы

### 1. PR-инструмент
Веб-версия позволяет пользователю увидеть программу до скачивания APK.

### 2. Бесплатный инструмент для автотестирования
Поскольку веб-версия работает 1:1 с нативным приложением, мы получили бесплатный инструмент для автоматического тестирования GUI. Теперь мы используем Microsoft Playwright для запуска тестов через GitHub Actions.

### 3. Замена ручной работы
Раньше тестирование GUI требовало ручной проверки на смартфоне. Теперь Playwright делает это автоматически.

## Вывод

Веб-версия — это двойное преимущество: PR-инструмент и бесплатный инструмент для автотестирования.
