# DeepSeek Harness на Android: от 4 часов ада до 4 минут в облаке

## Введение

Помните, как в прошлый раз мы «запрягали» DeepSeek Harness (DSH) на телефоне? Это был настоящий квест: нужно было установить Termux, ввести десятки команд, а потом полтора часа смотреть, как телефон греется и пытается собрать какие-то «нативные модули». Если что-то шло не так, всё приходилось начинать заново.

Сегодня мы решим эту проблему раз и навсегда. Мы перенесем самую сложную часть — «сборку движка» — в облако. Вам больше не нужно быть программистом или ждать, пока телефон справится с непосильной задачей. Мы просто скачаем готовую «запряжённую лошадь» и запустим её одной командой.

**Что изменилось?**

Раньше: Вы (и ваш телефон) делали всю черную работу.

Теперь: GitHub Actions (мощные компьютеры в облаке) делают сборку за нас. Мы подготовили репозиторий **[dsh-builder](https://github.com/x2v0/dsh-builder)**, который собирает идеальный архив под Android ARM64. Вам останется только скачать его и распаковать.

## Основная часть

Задача запуска DSH на Android/Termux всегда упиралась в кросс-компиляцию нативных C++ аддонов (`koffi`, `node-pty`, `system.node`) и специфику файловой системы Android (ограничения на `hard links`, отсутствие `flock`). `dsh-builder` решает это, перенося сборку в CI/CD.

### 1. Как это работает (Pipeline)

Репозиторий **[dsh-builder](https://github.com/x2v0/dsh-builder)**, это не форк DSH, а набор патчей и скриптов для GitHub Actions. Он не хранит исходники DSH, а загружает их в CI из официального репозитория **[deepseek-ai/deepseek-harnes](https://github.com/deepseek-ai/deepseek-harnes)**.

*   **Триггер:** Запуск `gh workflow run build-dsh.yml` или Push в `main`.
*   **Сборка:** GitHub Actions запускает Ubuntu runner с Node.js 24 и Android NDK.
*   **Патчинг:** Скрипты из `scripts/` и `patches/` автоматически применяют фиксы:
    *   `patch_flock.py` — заменяет `flock()` на `fcntl()` в `system.node`.
    *   `package.py` — генерирует правильную структуру `node_modules`, подкладывает пре-билды `koffi`, `node-pty`, `require_builtin`, а также патчит `session-persistence`, заменяя `link` на `rename` (обход `EACCES` на Android).
*   **Артефакт:** На выходе получается `dsh-android-arm64.tar.gz` — архив, готовый к запуску.

### 2. Быстрый старт для разработчика

1.  **Клонируйте репозиторий** (или используйте свой форк):
    ```bash
    git clone https://github.com/x2v0/dsh-builder.git
    cd dsh-builder
    ```

2.  **Запустите сборку в облаке:**
    Вам нужен установленный [GitHub CLI](https://cli.github.com/) (`gh`).
    ```bash
    gh workflow run build-dsh.yml --ref main
    ```

3.  **Следите за прогрессом:**
    ```bash
    gh run list --workflow=build-dsh.yml
    # Скопируйте ID запуска и подпишитесь на обновления
    gh run watch <ID_ЗАПУСКА>
    ```

4.  **Скачайте готовый артефакт:**
    После завершения сборки скачайте архив.
    ```bash
    gh run download <ID_ЗАПУСКА> -n dsh-android-arm64
    ```

5.  **Установка на телефон (Termux):**
    Перекиньте скачанный архив на телефон (например, через `adb push` или облако). В Termux выполните:
    ```bash
    tar -xzvf dsh-android-arm64.tar.gz
    cd dist-artifact
    
    # Экспортируем переменные окружения
    export DSH_HOME="$HOME/.dsh-sessions"
    # Опционально: если нужен обход hard links (на старых прошивках)
    # export LD_PRELOAD="$PWD/nolink.so" 
    export DEEPSEEK_API_KEY="sk-dummy" # Замените на ваш ключ или прокси
    
    # Запуск!
    node --import tsx/esm apps/cli/src/bin.ts web
    ```

### 3. Разбор ключевых патчей

В `dsh-builder` собраны решения проблем, с которыми сталкивается каждый, кто запускает DSH на Android:

*   **`flock -> fcntl`:** Android (bionic) не поддерживает `flock()`. Мы патчим C-код на использование `fcntl()`, который работает.
*   **`link -> rename`:** Android блокирует создание `hard links` (ошибка `EACCES`). Мы заменяем вызовы `fs.link` на `fs.rename` в `session-persistence`, `attachment-local` и `fs-local`.
*   **esbuild:** Termux определяет платформу как `linux`, а esbuild ищет `@esbuild/linux-x64`. Скрипт `package.py` подменяет бинарник на `android-arm64`.
*   **`FiberState`:** `tsx` не может импортировать `const enum` из `cordis`. Скрипт генерирует локальную константу в `profile-boot.ts`.

### 4. Важное примечание

Этот репозиторий — **не форк DSH**. Он не содержит исходного кода DSH. Это набор инструментов для сборки. Если вы хотите внести изменения в сам DSH, делайте это в официальном репозитории. `dsh-builder` лишь адаптирует его для запуска на Android.
